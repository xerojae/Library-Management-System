# Library Management System

## Overview

The Library Management System is a Java application designed to help libraries manage books, members, and borrowing activities. The system allows users to add books, search records, register members, and track borrowed and returned books.

---

## Features

* Add, remove, and search books
* Register library members
* Borrow and return books
* Track book availability
* Display library records
* Menu-driven interface

---
